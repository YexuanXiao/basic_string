# [basic_string](https://github.com/YexuanXiao/basic_string)

[![Check](https://github.com/YexuanXiao/basic_string/actions/workflows/ci.yml/badge.svg)](https://github.com/YexuanXiao/deque/actions/workflows/ci.yml)

A fast and clean implementation of basic_string that uses portable C++23 code and accurately meet standard requirements. The implementation maximum optimizes the short string optimization, and avoids self-referencing. It supports constexpr, exception safety and suitable for teaching purposes.
